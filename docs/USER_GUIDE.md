# 利用ガイド（概要）

詳細な操作方法は、アプリ内ヘルプ（左メニュー下部「使い方・基準参照」）に集約しています。ここでは全体像と最初の一歩だけをまとめます。

## まず押さえる3つの考え方

1. **編集** — 表に入力する場所。入力は即座に作業データへ保存（自動保存あり）
2. **成果物へ反映** — 上部の［成果物へ反映］ボタンを押すと、編集内容が業務記述書・フロー図・RCM等の成果物表示へ反映されます
3. **プレビュー** — 各画面右上の「編集｜プレビュー」で入力用と提出用の表示を切替

## 最初の一歩

1. [アプリを開く](https://norimaki-audit.github.io/jsox-flow-builder/jsox_flow_builder.html)（PC推奨）
2. スタート画面で **「サンプルデータで試す」** を選ぶ
3. 「業務記述書」→「フロー図」→「RCM」の順に眺めると、同じデータから3つが生成されていることが分かります
4. どこかを編集 →［成果物へ反映］→ フロー図やプレビューが追随することを確認

## 自社データで始める

- **既存Excel/CSVがある場合**：スタート画面「既存Excel/CSVを取り込む」→ ファイル選択 → シート・ヘッダ行の指定 → 列マッピング（自動推定・保存可）→ プレビュー → 取込
- **ゼロから作る場合**：「テンプレートから新規作成」→ 販売・購買・在庫・固定資産・経費のひな形を選択

## 三点セットの紐づけルール（重要）

- フロー図は業務記述書の**上から順**に自動接続。「判断」の行だけ Yes先/No先 に飛び先の工程No.を入力
- RCM の**「対象ステップNo.」**に業務記述書の工程No.を入れると、フロー図に R（リスク）/C（統制）タグが付きます
- 工程No.は 10, 20, 30… と10刻みにしておくと、間への挿入が楽です

## 保存

- **自動保存**：編集の数秒後にブラウザへ（2世代・起動時に自動復元）
- **正本**：ファイルメニュー「プロジェクトを保存(.json)」— バックアップ・PC間の移動はこれで
- **出力**：右上「Excel出力」から画面に応じた出力／三点セット一式／draw.io 等

## AI との使い方

上部「✨AIに相談」→ 目的を選んでコピー → お使いの AI に貼り付け → 回答を「回答を取り込む」タブへ貼り付け → 取込内容をプレビューして実行（Ctrl+Z で取消可）。詳しくはアプリ内ヘルプ「AI活用ガイド」を参照してください。

## オプション：評価管理

ファイルメニューの「評価・証憑管理機能」をオンにすると、整備・運用評価／サンプリング調書／評価結果／不備管理／証憑管理が左メニューに表示されます。オフに戻してもデータは消えません。

## 添付ファイル（証跡・証憑・規程資料）

- **添付できる形式**: 画像（png / jpg / gif / webp）、PDF、Office（xlsx / xls / docx / doc / pptx / ppt）、csv、txt、zip、msg、eml
- 安全のため、**HTML・SVG・実行ファイルは受け付けません**（悪意あるファイルがブラウザ上で動作するのを防ぐためです）
- **容量の上限**: 1ファイル5MB、1か所あたり20件、プロジェクト全体で合計25MB
  - ［保存先フォルダ…］を設定すると、PCのフォルダへ直接保存され、1ファイル50MBまで扱えます（Chrome・Edge）
- **開くとき**: 画像はアプリ内でプレビュー表示します。それ以外の形式は**ダウンロード保存**され、お使いのPCのアプリで開けます
