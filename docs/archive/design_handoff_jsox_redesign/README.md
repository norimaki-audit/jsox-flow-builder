# ハンドオフ: J-SOX 三点セットツール UI リデザイン

## 概要
内部統制（J-SOX）三点セット作成ツール `jsox_flow_builder.html` の UI/IA を刷新するためのハンドオフです。
配色・タイポ・情報設計・各画面の体裁・業務マニュアルモード・詳細パネル・テンプレート選択を、
既存のデータモデルと反映ロジックを維持したまま差し替えます。

## 適用先（重要）
- 対象は **既存の単一HTMLアプリ `jsox_flow_builder.html`**（バニラJS SPA／SheetJSインライン同梱）。
- **新規フレームワークへの移植ではない。** 既存ファイルの **見た目とIAだけ** を差し替える。
- **データモデル・反映モデル・入出力ロジックは変更しない**：
  `db`（正本）／`P()`（入力）／`outProc()`（成果物）／`applyAll()`（反映）／Excel・CSV・draw.io・Mermaid 入出力。
- 同梱の `HANDOFF.md`（リポジトリ既存）の関数マップ・命名・グリッド配線
  （`arrOf`/`onGrid`/`gridClick`/`attachDrag`、`inp/sel/chk`、`renderX`、`show()`、`MODE_CONFIG`）に合わせること。

## このバンドルのファイルは「デザインリファレンス」
- `J-SOX 三点セット リデザイン.dc.html` は **HTMLで作った意図伝達用プロトタイプ**であり、そのまま実装に貼るものではない。
- 実装は、このプロトタイプの**見た目・挙動を、既存 `jsox_flow_builder.html` のバニラJS + 既存関数の上で再現**する。
- ブラウザで直接開けば全画面・全モードを操作して確認できる（`support.js` 同梱）。

## フィデリティ
**ハイファイ（hifi）**。配色・タイポ・余白・記号・インタラクションは確定値。ピクセル単位で再現してよい。

## 実装手順 ＝ `実装反映ガイド.md` を参照
セクション別の具体的な適用内容（既存関数への対応づけ込み）は、同梱の **`実装反映ガイド.md`** に集約してある。
そちらを唯一の実装仕様として進めること。要点のみ再掲：

1. **§1 デザイントークン** … `:root` のCSS変数（teal基調）＋ IBM Plex Sans JP/Mono ＋ Phosphor を `<head>` に追加
2. **§2 アプリバー＋左ナビ** … 「編集／成果物」の重複を各帳票内の **編集/プレビュー トグル**へ統合（`show()` はそのまま、`renderX` を呼び分け）。ナビは sticky＋本体スクロール、ヘルプ下部固定。モード切替・プロセス選択・プロセス追加。
3. **§3 業務記述書グリッド** … 業務グルーピング（色帯）・種類バッジ・部署カラーチップ・点線区切り・📝詳細パネル
4. **§4 フロー図** … JIS X 0121 標準記号（端子/処理/手作業=台形/判断=ひし形/書類=波形下辺/DB=シリンダ）・はい/いいえ2分岐・R/Cタグ・フェーズ区切り
5. **§5 RCM** … アサーション colspan ヘッダ・KC=○・評価ピル・点線区切り・列トグル
6. **§6 ダッシュボード/評価・点検** … KPI・評価進捗バー・網羅マトリクス・不備3段階・証憑／評価結果・ギャップ・ロールフォワード・不備・証憑の各画面
7. **§7 業務マニュアルモード** … `MODE_CONFIG.manual` 拡張（ページ非表示・用語切替・R/C非表示・画像添付）
8. **§8 詳細パネル（📝）** … `step.detail` 入力/閲覧、プレビュー側は本文展開、マニュアルは画像インライン
9. **§9 テンプレート選択** … 「プロセス追加」→ 業種別ひな形 → `addProcess()`

## 検証（適用後・必須／`HANDOFF.md` §8）
- `python3 check.py`（handlers未定義 / getElementById不在 / nav↔page不一致 = none）
- `node --check main.js`
- `node smoke.js`（loadExample → applyAll → 各 show(pg) → exportXlsx が例外なし）
- 目視：J-SOX/マニュアル両モード、編集/プレビュー両ビュー、印刷（@media print）

既存の商用J-SOXツールのUI/ブランド/独自記法は複製しない。配色・ロゴ（IC Studio）は独自、記号は公知のJIS標準のみ。

- フォント: 日本語 IBM Plex Sans JP / 数値・ID・金額・日付 IBM Plex Mono
